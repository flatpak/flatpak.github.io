Flatpak is developed by an independent community, made up of contributors, volunteers and supporting organizations. It is a true upstream open source project, dedicated to providing technology and services that can be used by all, with no vendor lock-in. We have strong links to other Free Software projects, including the Freedesktop project.

All our code is freely available, with no contributor agreement required. Volunteers and contributing organizations are welcome, as equal partners.

## Flatpak History

<div class="timeline">
  <div class="date">August 2007</div>
  <div>Alexander Larsson releases Glick, his first app bundling framework</div>

  <div class="date">November 2011</div>
  <div>Glick 2 is released, a modernized version of the first Glick framework</div>

  <div class="date">July 2012</div>
  <div>"GNOME OS" session held at GUADEC, includes initial planning for a new app bundling format</div>

  <div class="date">September 2012</div>
  <div>Alexander Larsson releases experimental "bundler" framework</div>

  <div class="date">January 2013</div>
  <div>"Linux Apps" proposal discussed at the GNOME Developer Experience hackfest, Brussels</div>

  <div class="date">December 2014</div>
  <div>Work begins on xdg-app, which later becomes Flatpak</div>

  <div class="date">March 2015</div>
  <div>xdg-app 0.1 released, the very first version of Flatpak</div>

  <div class="date">December 2015</div>
  <div>GNOME's "Software" gains the ability to install xdg-app applications</div>

  <div class="date">May 2016</div>
  <div>xdg-app renamed to Flatpak, 0.6.0 released; <a href="/press/2016-06-21-flatpak-released/">accompanying press release</a> included endorsements by Red Hat, Endless Computers and Collabora</div>

  <div class="date">June 2016</div>
  <div>Work on desktop portals security framework begins</div>

  <div class="date">June 2016</div>
  <div>LibreOffice is the first major application to adopt Flatpak for publishing on Linux</div>

  <div class="date">July 2016</div>
  <div>GTK+ 3.21.4 released with initial support for the portals framework</div>

  <div class="date">August 2016</div>
  <div>Endless OS 3.0 released, the first publicly available OS to use Flatpak by default. Adoption of Flatpak by Apertis IVI also becomes public knowledge.</div>

  <div class="date">November 2016</div>
  <div>ClearLinux announces their adoption of Flatpak</div>

  <div class="date">December 2016</div>
  <div>Flatpak 0.8.0 released, the start of the first stable series with long-term support</div>

  <div class="date">May 2017</div>
  <div>Initial soft launch of Flathub hosting service</div>

  <div class="date">May 2017</div>
  <div>KDE Plasma 5.10 released with initial support for portals</div>

  <div class="date">October 2017</div>
  <div>Flatpak 0.10.0 released, marking the start of the second supported stable release series</div>

  <div class="date">October 2017</div>
  <div>KDE Plasma 5.11 released, "Discover" gains the ability to install Flatpak apps</div>

  <div class="date">October 2017</div>
  <div>GIMP adopts Flatpak to publish on Linux</div>

  <div class="date">November 2017</div>
  <div>Linux Mint 18.3 released, includes out of the box Flatpak integration</div>

  <div class="date">August 2018</div>
  <div>Flatpak 1.0 released, the first release in a new stable series, with major new features; Flathub beta period ends; Freedesktop runtime 18.08 released with new support period policy</div>

  <div class="date">September 2018</div>
  <div>KDE introduces the KDE Testing Applications Flatpak repository; <a href="https://invent.kde.org/packaging/flatpak-kde-applications/-/commit/2d759a0d601942c3cf3a1d6a562942da543f7f83">commit</a></div>

  <div>System76 releases Pop!_OS 20.04, includes out of the box Flatpak integration</div>
